---
title: Glossary
description: A compact glossary for the product terms used in Compartment docs.
---

- `base domain`: the install-level public domain used for the control plane and canonical app hosts.
- `binding`: the association between a Git source and one discovered descriptor app.
- `control plane`: the API and CLI-managed management surface for installs, orgs, projects, access, and deployments.
- `deployment`: one rollout for one service.
- `descriptor`: the `compartment.yml` file that defines a project and its services.
- `environment`: the named target runtime environment for a project.
- `install`: one Compartment runtime with one control plane and one public host family.
- `managed domain`: a broker-allocated install base domain.
- `project`: the canonical application identity derived from the descriptor.
- `remote`: a named CLI profile for one logged-in Compartment install.
- `service`: one deployable unit inside a project.
- `source upload`: the uploaded source archive used as deployment input before the build starts.
