Sizes

Names are the `size` values from `components/ui/button.tsx`; omitted size resolves to `md`.

Size Height Padding Text Use
xs 24px 8px inline, 6px icon gap 12px / medium Pagination, copy controls, compact icon buttons.
sm 32px 10px inline, 8px icon gap 12px / medium Table actions, drawer actions, compact forms.
md 36px 14px inline, 8px block, 8px icon gap 13px / medium Default button size for forms and page actions.
default 36px Same as md 13px / medium Legacy size alias kept by `buttonVariants()`.
lg 40px 18px inline, 8px block, 8px icon gap 13px / medium Available for rare high-emphasis flows; not used for page CTAs now.
